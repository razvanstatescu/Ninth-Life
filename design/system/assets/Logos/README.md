# Logos

The icon is the logo. Both files are full-bleed squares on night `#140a2e`, so they work as normal and maskable PWA icons: everything important sits inside the central circle with a radius of 40% of the width.

- `ninth-life-icon.svg`: the full icon. Moon bubble with cat ears, eight plum keys and the ember ninth key. Use at 48px and above: app icon, website header, video end card, social avatar.
- `ninth-life-favicon.svg`: the small-size variant. Same bubble, one plum-ringed ember key, no dark keys. Use below 48px: favicon, browser tab, 16 to 32px UI.

Colors are fixed: night `#140a2e`, moon `#eee8ff`, plum `#2a1856`, ember `#ffb13d`. There is no single-ink version yet; on a photo, place the icon tile whole. Clear space is one key's width on every side. Do not recolor the ember key, rotate the icon, add a face, crop the ears or place the icon on a phone drawing.
