# Assumptions register

What the source plan (`docs/plan/00-source-plan.md`) assumed about Kiro, the hackathon rules, the web platform and the regulatory position, checked against primary sources. Every row was checked on **2026-11-06** unless it says otherwise. Kiro moves fast: re-check a row before you rely on it after a Kiro release.

Status values:

- **verified**: the source says what the plan says.
- **corrected**: the source says something different; the "consequence" column says what we changed.
- **unverified**: not confirmed this session (source missing, or not checked).
- **open**: a question the sources do not answer.

This file may quote banned trademark words where a source needs them; nothing else in the repo may (see `.kiro/steering/trademarks.md`). The legal rows are a risk note, not legal advice.

## Summary of changes against the plan

1. **Hook payloads (plan open question 6): answered.** Command hooks get the event as JSON on STDIN; file triggers can also use the `{{filePath}}` template; UserPromptSubmit also sets `USER_PROMPT`. Field names inside `tool_input` are still undocumented (H-03).
2. **Exit codes need care.** Exit 2 blocks; any other non-zero is an error, and on exit 0 STDOUT is **added to the agent's context**. Only STDERR reaches the agent on failure, so test and typecheck hooks must send output to STDERR (H-06).
3. **Tool matchers.** `fs_write|str_replace` is not portable: tool IDs differ by surface and engine. Use categories (`write`, `shell`) or a regex over several spellings (H-04).
4. **Agent configs:** `allowedTools` is CLI 2.x legacy (V3 skips such profiles); use `permissions.rules`. Inline `hooks` in an agent are CLI-only and **the IDE ignores any agent that contains them** (A-03, H-09).
5. **Headless CLI:** add `--v3` (headless runs default to V2), `--trust-tools` takes exact V3 tool IDs (`read_file,grep_search`, not `read,grep`), the plan list adds Pro Max, and `KIRO_LOG_NO_COLOR` is not a documented variable (C-02, C-03).
6. **Powers:** the recommended format is now Agent Plugins (`plugin.json` + `skills/`); `POWER.md` still works. "AWS Cost Optimization" is a community power, not an AWS one; the power builder is listed as "Build a Power" (PW-01, PW-03).
7. **Context7:** prefer the remote server `https://mcp.context7.com/mcp`; the old npm GitHub MCP server is archived; the remote GitHub MCP needs a PAT because GitHub does not support dynamic client registration (M-03, M-06).
8. **Fonts and Next.js:** `next/font/google` only knows "Atkinson Hyperlegible Next" and "Atkinson Hyperlegible Mono" from **Next.js 15.4.0**; the repo pins 15.1.3 (the web package already self-hosts the fonts, so nothing breaks today). The pinned Next 15.1.3 and React 19.0.0 are inside the CVE-2025-66478 / CVE-2025-55182 range (critical RSC remote code execution): the web owner should upgrade (W-04, W-05).
9. **Models:** Claude Haiku 5.5 is GA (Active since Oct 23, 2026), not experimental (MO-01).
10. **Judging:** Kiro use is scored in one of five equal criteria (Technological Implementation, 20%) plus the Stage One pass/fail gate, and "insufficient use of Kiro" can disqualify (R-02).
11. **Crew:** `apps_allow_third_party` is not in the current docs (K-05). Node 22+ (not 22.12+) is only needed to build the dashboard from source (K-06).
12. **Plan open question 7:** "morse-aac-decoder" re-found; it was created on 2026-10-06, before the submission period (see `competitive-landscape.md`).
